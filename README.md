# 聚合英语

> 一个纯前端、离线可用的英语学习单页应用：词汇 · 语法 · 影视 · 文学 · 打卡 · 笔记。

聚合英语是一个完全本地运行的英语学习工具。所有词库、语法、谚语、影视与文学数据都存放在 `vocal.js` 中，应用逻辑集中在 `index.html`，无需后端、无需注册、无需联网即可使用。学习进度、错题本、收藏、打卡记录等全部保存在浏览器 `localStorage` 中。

---

## 在线体验

- 官方地址：<https://littlegbrc.cn>
- 离线使用：下载 `index.html` 和 `vocal.js`，放在同一目录，双击 `index.html` 即可。

## 功能特性

### 学习

- 六大学段词库：小学、初中、高中、四级、六级、考研
- 可自选每次学习的单词数量，也支持导入自己的 JSON 词库
- 学习流程可自定义、可增删、可排序：
  - 朗读认知
  - 中译英
  - 英译中
  - 听音选词
  - 拼写
  - 句子选词
  - 跟读训练
- 选择题模式与手动输入模式可切换
- 中文释义智能判分：写近义词、写得更简略也可能判对
- 每轮结束给出 D ~ S 综合评级，并可生成评价分享图

### 复习与考试

- 按已学单词、错题本、收藏本复习
- 试卷式完形填空：自动生成短文与选项，交卷后逐题对照
- 语法填空：在连贯短文中填写单词
- 听写模式：听发音写单词，可设置朗读内容、遍数、间隔
- 小短文生成：用所学单词组成连贯短文

### 词典与词汇工具

- 全站词典：A–Z 索引、按已学 / 未学 / 错题筛选
- 同义反义总览：近义词辨析、反义词对照
- 构词法库：前缀、后缀、词根、衍生词，支持按词性筛选
- 形容词变化：比较级与最高级，含构成规则
- 不规则动词表：按学段分类，可搜索
- 中文近义判定：内置中文近义词组，提高释义判分容错

### 笔记模式

- 按学段、错题本、收藏本选词，或随机选 N 个词
- 生成 A4 / B5 / A5 / A6 笔记本大小的单词笔记
- 可自定义字体大小、行数、列数、模块颜色、模块顺序
- 支持横线款、方格款、空白内页
- 电脑端左右双页预览，手机端单页翻页
- 可生成打印页，也可直接保存为 PDF
- 笔记中所有单词可点击查看详情

### 影视库 / 文学库

- 内置 200+ 部影视作品与 200+ 本文学作品信息
- 可按类型、子类、难度、年代筛选，支持排序与收藏
- 支持写观后感 / 读后感，自动标注第几遍
- 提供主流平台直达搜索链接，方便在线观看或找书

### 每日打卡与学习报告

- 日历热力图：连续天数、最长连续、累计单词、学习时长、正确率
- 可生成多种样式的打卡分享图
- 学习报告：历史评价、评级分布、平均综合分、用时统计
- 学习日程：设置每周计划、指定某天目标、休息日

### 文本标注

- 粘贴英文文本，自动统计单词数与段落数
- 词库内单词标蓝下划线，点击可查看详情
- 词库外单词标红，点击可填写音标、词性、词义、变化形式、近义反义，并收录到“我的词库”

### 词库管理与数据备份

- 支持导入 JSON 词库
- 多词库并行启用
- 可导出我的词库、全部词库、当前学段、按分类导出
- 可导入 / 导出配置包（ZIP / JSON），包含：
  - 偏好设置
  - 自建词库
  - 错题本
  - 收藏本
  - 打卡记录
  - 学习报告
  - 观后感
  - 学习日程
  - 学习痕迹

### 外观与设置

- 8 套主题配色，每套都有暗色版本
- 夜间模式、自动夜间模式
- 字号、背景色、页面缩放
- 简化布局 / 标准布局
- 侧边栏分类管理：折叠、重命名、增删分组、移动功能
- 朗读速度、自动发音、倒计时、听写参数等均可调整

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript
- 无框架、无依赖、无构建步骤
- 数据存储：`localStorage`
- 语音朗读：Web Speech API
- 语音识别：SpeechRecognition / webkitSpeechRecognition
- 二维码生成：纯 JS 实现，按 ISO/IEC 18004 字节模式生成
- ZIP 打包 / 解包：纯 JS 实现
- PDF 导出：Canvas 栅格化 + 手写最小 PDF
- 图片导出：Canvas + Blob 下载
- 响应式布局：桌面端侧边栏、平板图标导轨、手机底部导航

## 快速开始

### 本地运行

1. 下载或克隆本仓库。
2. 确认 `index.html` 与 `vocal.js` 在同一个文件夹中。
3. 双击 `index.html`，或拖入浏览器打开。
4. 推荐使用 Chrome / Edge / Safari 获得完整功能。

### 部署到静态托管

将 `index.html`、`vocal.js` 以及可选的反馈图片上传到任意静态托管服务即可，例如：

- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages
- 任意支持静态文件的服务器

无需数据库、无需 Node.js、无需构建命令。

## 导入自己的词库

在「词库管理」中可导入标准 JSON 词库。推荐格式：

```json
[
  [
    "apple",
    "/ˈæpl/",
    "n. 苹果",
    [
      ["An apple a day keeps the doctor away.", "一天一个苹果，医生远离我。", "谚语"]
    ]
  ]
]
```

字段说明：

- 第 1 项：单词
- 第 2 项：音标，可为空字符串
- 第 3 项：释义
- 第 4 项：例句数组，每条例句为 `[英文, 中文, 出处]`

也兼容部分其他 JSON 结构。导入后会自动启用，并出现在「我的词库」学段中。

## 配置分享与备份

在「词库管理 → 分享配置包」中，可以勾选需要导出的内容，导出为 ZIP 文件。ZIP 中包含：

- `README.txt`
- `config.json`
- `data.json`

在另一台设备上，通过同一入口导入即可恢复配置。适合备份学习记录，或把词库、错题、收藏迁移到别的浏览器。

| 浏览器 | 朗读 | 语音识别 | 说明 |
| --- | --- | --- | --- |
| Chrome / Edge | 支持 | 支持 | 推荐，功能最完整 |
